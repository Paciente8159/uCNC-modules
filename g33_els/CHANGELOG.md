# About G33-ELS for µCNC

This module adds custom G33 code to the µCNC parser. This similar to Linux CNC G33 and allows to make motions synched with the spindle in µCNC.
The ELS version as several additional features relative to the old G33 module.

These include:

 - Multiple index events per rev
 - Hardware controller feedback
 - Configurable compensation gain
 - RPM Smoothing
 - Acceleration compensation
